## 1. 개요

주보·소식·설교·기도·소그룹을 한 곳에서 제공하는 교회 공동체 앱입니다.
**Expo(React Native) 한 코드베이스**로 iOS·Android·웹(PWA)을 모두 지원하며,
현재는 **웹(PWA)** 을 GitHub Pages로 배포해 서비스 중입니다.

백엔드는 **Supabase**(PostgreSQL + 인증 + 스토리지 + Edge Functions)를 사용하고,
설정이 없을 때는 **샘플 데이터 모드**로 서버 없이도 전체 화면을 볼 수 있습니다.

## 3. 주요 기능

- **홈** — 오늘의 말씀(매일 순환), 빠른 메뉴, 이번 주 예배, 실시간 예배 배지, 나의 기도 요약
- **주보** — 지난 주보 목록·상세(예배 순서·광고·원본 이미지), 관리자 사진 업로드
- **소식** — 공지/행사/소식 분류, 상단 고정, 상세
- **설교** — 시리즈·쇼츠 목록(유튜브 연동), 앱 안 재생
- **기도** — 타이머·빠른 기록, 개인/공동 분리, 달성률·달력·평균 시각화, 기도제목 나눔(익명·함께 기도·응답), 기도 알림
- **소그룹** — 목록과 소통방(채팅)
- **교회 안내** — 예배 안내·섬기는 사람들·오시는 길·새가족·헌금
- **관리자** — 주보·공지·설교·소그룹·공동 기도제목 관리, 실시간 배지 수동 제어

## 4. 이번 개선 내역 (최근 작업)

### 4.1 기도 알림 — 웹 푸시 알림 시스템 신규 구축 ⭐
성도가 정한 **요일·시간에 기도 알림**을 받도록 전체 파이프라인을 구축했습니다.

- **클라이언트**(`src/lib/reminders.ts`, `src/app/reminders.tsx`)
  - 서비스워커 등록 → 알림 권한 요청 → PushManager 구독 → 구독 정보를 Supabase에 저장
  - 설정 화면: 요일 다중 선택, **오전/오후 탭 + 시(1~12)·분(00~59)** 선택
  - **"테스트 알림 보내기"** 버튼으로 표시 여부 즉시 확인
- **서비스워커**(`public/sw.js`)
  - push 수신 시 알림 표시(진동 패턴·requireInteraction 포함), 클릭 시 앱 열기
- **서버**(`supabase/functions/send-reminders/index.ts`)
  - `npm:web-push` 사용, 매분 호출되어 "지금(사용자 시간대) 보낼 대상"을 찾아 발송
  - 만료된 구독(404/410)은 자동 정리, 하루 1회 발송 보장(`last_sent_date`)
- **스케줄**(`supabase/cron-reminders.sql`)
  - pg_cron + pg_net 으로 매분 함수 호출
- **데이터**: `push_subscriptions` 테이블(엔드포인트·키·요일·시간·시간대·활성 여부)

> 구축 과정에서 확인한 배포 요건: Edge Function은 **Verify JWT OFF**,
> 호출 시 **`apikey` 헤더에 publishable 키** 필요(신규 API 키 체계), VAPID 공개/개인키 2종 등록.

### 4.2 기도 화면 시각화 개편
- 참조 디자인에 맞춰 **달성률 게이지(반원)**, **최근 10일 평균 막대 그래프** 추가
- "나의 기도 기록"을 **월 달력** 형태로 변경(기도한 날 표시·월 이동·연속 일수)
- **개인/공동 기도 토글**, 주간 목표(±30분) 설정
- 개인 기도제목·기도 요청 진입 카드 재정비

### 4.3 기도 타이머 정확도 수정
- 기존: 몇 초만 지나도 **무조건 1분**으로 집계되던 문제(`Math.max(1, …)`)
- 수정: 실제 경과 시간을 **가장 가까운 분**으로 기록(30초 미만은 미기록)

### 4.4 실시간 예배 자동 감지
- 교회 유튜브 라이브 상태를 감지해 홈 **LIVE 배지** 자동 표시
  (`supabase/functions/live-status`, `src/lib/live-status.ts`)
- 단발성 확인 실패로 배지가 꺼지지 않도록 **히스테리시스** 안정화
- 관리자 **강제 ON/OFF 스위치**, 캐시 120초로 무료 할당량 여유 확보

### 4.5 주보 이미지 처리 개선
- 원본 이미지가 삭제/404 일 때 **까만 빈칸 대신 안내 문구** 표시
- 주보 편집에서 **URL 붙여넣기 제거 → 사진 업로드 방식만** 사용

### 4.6 기타
- 나의 기도 시간을 **로그인 계정별 서버 저장**(기기 간 유지) + 로컬→계정 1회 동기화
- 시작(표어) 화면, 오늘의 말씀 배너, 개인/공동 기도제목 분리 등

## 5. 아키텍처 요약

```
[앱(웹/PWA)] ──> ChurchRepository 인터페이스
                    ├─ 샘플 저장소 (기기 로컬)
                    └─ Supabase 저장소 (DB·Auth·Storage)

[기도 알림 흐름]
앱: 서비스워커 구독 → push_subscriptions 저장
Supabase pg_cron(매분) → send-reminders 함수 → Web Push → 서비스워커 → 알림 표시

[실시간 예배]
앱 → live-status 함수(유튜브 확인, 120초 캐시) → LIVE 배지
```

- 화면 코드는 `ChurchRepository` 인터페이스만 사용 → 환경변수만으로 백엔드 교체
- RLS 정책으로 읽기/쓰기 권한 관리(공개 읽기 + 관리자/본인 쓰기)
