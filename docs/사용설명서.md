# 구리 목양교회 앱 — 사용설명서

주보·소식·설교·기도·소그룹을 한 곳에서 볼 수 있는 교회 공동체 앱입니다.
휴대폰(안드로이드·아이폰)과 PC 어디서나 브라우저로 열 수 있고, "홈 화면에 추가"하면 앱처럼 실행됩니다.

- **앱 주소:** https://byunghoonchoi76.github.io/first-repository/

## 1. 처음 시작하기 (설치)

앱은 설치 없이 브라우저로 바로 쓸 수 있지만, **"홈 화면에 추가"** 하면 아이콘이 생기고
주소창 없이 앱처럼 열리며 **기도 알림도 더 안정적으로** 옵니다.

### 안드로이드 (크롬)
1. 크롬으로 앱 주소를 엽니다.
2. 우측 상단 **⋮ (더보기)** → **홈 화면에 추가** → **설치**.
3. 홈 화면에 생긴 **목양교회** 아이콘으로 실행합니다.

### 아이폰 (사파리)
1. **사파리**로 앱 주소를 엽니다. (크롬 말고 사파리여야 알림이 됩니다)
2. 하단 **공유 버튼(⬆️)** → **홈 화면에 추가**.
3. 홈 화면 아이콘으로 실행합니다.
   > 아이폰은 이렇게 **설치한 앱으로 열어야만** 기도 알림을 받을 수 있습니다. (iOS 16.4 이상)

## 2. 화면 둘러보기

하단 탭으로 주요 화면을 이동합니다.

| 탭 | 내용 |
| --- | --- |
| **홈** | 오늘의 말씀(매일 순환 성경구절), 빠른 메뉴, 이번 주 예배, 실시간 예배(LIVE 배지), 나의 기도 요약, 최근 소식·설교 |
| **소식** | 공지 / 행사 / 소식, 상단 고정글, 상세 보기 |
| **설교** | 교회 유튜브 채널 영상을 카테고리별로 자동 정리, 앱 안에서 바로 재생(쇼츠는 세로 화면) |
| **기도** | 기도 타이머, 달성률·달력·평균 그래프, 기도제목 나눔, 기도 알림 설정 |
| **소통방** | 내가 초대된 소통방 목록과 대화방(초대제) |

이 밖에 **교회 안내**(예배 안내·섬기는 사람들·오시는 길·새가족·헌금)와
**더보기**(로그인·교회 정보·유튜브 채널 연결)가 있습니다.

## 3. 기도 기능 사용법

**기도 탭**에서 개인 기도와 공동 기도를 나눠 기록하고, 한눈에 볼 수 있습니다.

### 개인 / 공동 전환
화면 상단의 **개인 · 공동** 토글로 바꿉니다.
- **개인 기도** — 나의 기도 시간을 기록합니다.
- **공동 기도** — 교회가 함께 정한 기도 시간에 내가 참여한 시간을 기록합니다.

### 기도 시간 기록하기
1. **"기도 시작"** 을 누르면 타이머가 흐릅니다 (분:초 표시).
2. 기도를 마치면 **"마치고 기록하기"** 를 누릅니다.
3. 실제 기도한 시간이 **정확히 분 단위로** 기록됩니다.
   - 30초 미만은 기록되지 않습니다. (짧은 오작동 방지)
   - 예: 3분 40초 기도 → 4분으로 기록.
4. 빠른 기록이 필요하면 **+5분 / +10분 / +30분** 버튼을 눌러도 됩니다.
5. 잘못 기록했으면 **"오늘 기도 기록 지우기"** 로 오늘 것을 지울 수 있습니다.

### 한눈에 보는 통계
- **달성률 게이지** — 이번 주 목표 대비 기도 시간 (목표는 ± 30분 버튼으로 조정)
- **나의 기도 기록(달력)** — 기도한 날은 초록 동그라미, 오늘은 테두리 표시. 월 이동 가능.
- **연속 일수** — 며칠째 이어서 기도했는지
- **최근 10일 평균** — 막대 그래프로 최근 흐름 확인

### 기도제목 나누기
- **개인 기도제목** / **기도 요청** 카드로 들어가 제목을 올릴 수 있습니다.
- 올릴 때 **익명**으로도 가능하고, 다른 성도가 **"함께 기도"** 로 마음을 보탤 수 있습니다.
- 내가 올린 개인 기도제목은 카드의 **연필(✎)** 아이콘으로 **수정·삭제**할 수 있습니다.
- 응답된 기도는 **응답 표시**를 할 수 있습니다.
- **기도 요청** 화면 맨 위 **우리의 기도노트**에서 “하나님께서 우리 삶에서 일하고 계십니다.” 문구와 함께
  **기도제목·기도 중·응답됨·함께 기도** 현황을 온 성도가 함께 확인합니다.

## 4. 기도 알림 받기 (요일·시간 알림)

정한 **요일과 시간**에 "기도할 시간이에요 🙏" 알림을 휴대폰으로 받을 수 있습니다.

### 켜는 방법
1. **기도 탭 → 기도 알림** (또는 더보기 → 기도 알림) 으로 들어갑니다.
2. 위쪽 **"기도 알림 받기"** 를 켜고, 브라우저가 물으면 **허용**합니다.
3. 알림마다 **요일**(여러 개 선택 가능)을 켜고,
4. **시간**을 정합니다 — **오전/오후** 탭, **시(1~12)**, **분(00~59)** 을 골라요.
5. **"이 설정으로 저장"** 을 누르면 끝입니다.

이후 정한 요일·시간이 되면 자동으로 알림이 옵니다.

### 한 사람당 최대 3개
- **"알림 추가"** 를 누르면 **서로 다른 시간의 알림을 최대 3개**까지 만들 수 있습니다.
  (예: **새벽 5:30 · 점심 12:00 · 밤 9:00**)
- 각 알림 오른쪽 위 **휴지통**으로 지울 수 있습니다.

### 확인·팁
- **"테스트 알림 보내기"** 버튼을 누르면 알림이 잘 뜨는지 바로 확인할 수 있습니다.
- 알림은 **기기마다 따로** 설정합니다. 여러 기기에서 받고 싶으면 각 기기에서 한 번씩 켜 주세요.
- **소리·진동**은 휴대폰 설정을 따릅니다.
  - 안드로이드/PC는 브라우저에서 바로 받습니다.
  - 아이폰은 **사파리 → 홈 화면에 추가** 로 설치한 앱에서 열어야 알림이 옵니다.
  - 소리는 나는데 **진동이 안 오면**: 휴대폰을 **진동/소리+진동 모드**로 두거나,
    (삼성) **설정 → 알림 → 목양교회 → 알림 방식 → "소리 및 진동"** 으로 바꾸세요.

## 5. 실시간 예배 보기

주일 예배 등 교회 유튜브가 **실시간 방송 중일 때** 홈 화면에 **LIVE 배지**가 자동으로 켜집니다.
배지를 누르면 방송을 바로 볼 수 있습니다. 방송이 끝나면 배지도 자동으로 사라집니다.

---

## 6. 설교 영상 (유튜브 자동 연동)

교회 유튜브 채널과 연동되어, **URL을 복사해 붙여넣지 않아도** 설교 영상이 앱에 자동으로 나타납니다.

### 자동으로 채워지는 것
- **홈 “이번 주 말씀”** — 채널에 올라온 **가장 최신 영상**이 자동으로 표시됩니다.
- **설교 탭** — 채널 영상을 제목으로 읽어 **카테고리별로 자동 분류**해 보여 줍니다.
  (주일예배 · 새벽예배 · 수요예배 · 금요집회 · 찬양 · 쇼츠 · 기타)
- 위쪽 **카테고리 칩**으로 원하는 종류만 골라 볼 수 있고, 항상 **최신순**으로 정렬됩니다.
- 영상을 누르면 **앱 안에서 바로 재생**됩니다.

### 관리자 — 유튜브에서 불러오기
- 관리자 → 설교 등록 화면의 **“유튜브에서 불러오기”** 를 누르면 최근 영상 목록이 뜹니다.
- 하나를 고르면 **제목·날짜·주소가 자동으로 채워지고**, 설교자·본문·시리즈만 확인해 저장하면 됩니다.
- 설교 탭의 자동 목록에서도 관리자에게는 **“설교로 등록”** 바로가기가 보여, 설교자·본문을 덧붙일 수 있습니다.
  (등록하면 관리자 정보가 반영되고 목록에서 중복되지 않습니다.)

> 새로 올린 영상은 **최대 10분 안에** 앱에 반영됩니다. (유튜브 조회를 아껴 무료 한도 안에서 동작합니다.)

## 7. 소통방 (초대제 대화방)

소그룹(구역·목장)별 **비공개 대화방**입니다. **초대된 멤버만** 입장·대화할 수 있고, 대화 내용도 멤버끼리만 보입니다.

### 누가 무엇을 하나요
- **관리자**가 소통방을 만들고, 앱에 가입한 성도 중에서 **리더를 지정**합니다.
- **리더**는 방 오른쪽 위 **사람 아이콘 → 멤버 초대** 에서 성도 이름을 검색해 초대합니다.
- 초대받은 멤버가 방에 들어와 **대화**하고, 필요하면 **소통방 나가기** 도 할 수 있습니다.
- 초대되지 않은 분에게는 소통방이 **아예 보이지 않습니다.** (초대는 앱에 **가입/로그인한 적이 있는** 성도만 검색됩니다.)

### 새 글 알림 (개인별)
- 방의 **사람 아이콘 → "이 소통방 알림"** 을 켜면, 새 글이 올라올 때 **앱을 닫아 두어도** 알림을 받습니다.
- 알림은 **방마다 각자** 켜고 끌 수 있습니다.

## 8. 로그인과 내 기록

- 로그인 없이도 대부분의 화면을 볼 수 있습니다.
- **로그인**(더보기 → 로그인)하면, 나의 기도 시간이 **계정에 저장**되어
  기기를 바꾸거나 다시 설치해도 기록이 유지됩니다.
- 기도제목을 올리거나 "함께 기도"에 참여하려면 로그인이 필요합니다.

## 9. 관리자 사용법

관리자 계정으로 로그인하면 **관리자 화면**에서 콘텐츠를 직접 관리할 수 있습니다.

### 주보 등록
1. 관리자 → **주보** → 새 주보 추가.
2. 예배 날짜를 정하고, 예배 순서·광고를 줄 단위로 추가합니다.
3. **주보 원본 사진 올리기** — 촬영·스캔한 주보 이미지를 바로 업로드합니다.
   (가장 최근 날짜의 주보가 홈 화면에 표시됩니다.)
   > 원본 이미지가 삭제되어 안 보이면 앱이 "원본 이미지를 불러올 수 없습니다" 안내를 보여줍니다.

### 실시간 예배 배지 수동 제어
- 자동 감지가 기본이지만, 관리자 설정에서 **강제 ON/OFF** 스위치로
  배지를 직접 켜거나 끌 수 있습니다. (특별 방송 등에 활용)

### 설교 등록 (유튜브에서 불러오기)
- 관리자 → **설교 → 새 설교 등록** → **“유튜브에서 불러오기”** 로 채널 최근 영상을 골라
  제목·날짜·주소를 **자동으로 채웁니다.** (설교자·본문·시리즈만 확인해 저장)
- 설교 탭 자동 목록의 **“설교로 등록”** 바로가기로도 바로 보강할 수 있습니다.

### 소통방 만들기
- 관리자 → **소통방 → 새로 등록** 에서 방을 만들고, 성도를 검색해 **리더를 지정**합니다.
- 이후 **초대·대화**는 리더와 멤버가 진행합니다. (관리자는 모든 방을 볼 수 있습니다.)

### 가입자 현황·삭제
- 관리자 홈 **관리 현황**의 **가입자** 숫자를 누르면 **가입자 명단**(이름·역할·가입일)이 열립니다.
- 각 성도의 **휴지통** 아이콘으로 계정을 **삭제**할 수 있습니다.
  (계정과 그 성도의 기도 기록·소통방 참여 정보가 함께 지워지며 되돌릴 수 없습니다. 본인 계정은 삭제 불가.)

### 그 밖의 관리
- 관리자 홈 맨 위 **관리 현황**에서 주보·공지·소통방·가입자·설교 개수를 한눈에 봅니다.
- **공지 / 설교 / 섬기는 사람들** 등록·수정·삭제
- **공동 기도제목** 편집
- **새가족 등록 내역** 조회 (관리자만)

## 10. 자주 묻는 질문

**Q. 알림이 안 와요.**
- 앱을 완전히 종료 후 다시 열어 보세요(최신화).
- 기도 알림 화면에서 **"테스트 알림 보내기"** 로 표시 여부를 먼저 확인하세요.
- 아이폰은 **사파리에서 홈 화면에 추가로 설치한 앱**에서만 알림이 옵니다.
- 휴대폰 **설정 → 알림** 에서 목양교회(또는 크롬) 알림이 켜져 있는지 확인하세요.

**Q. 기도 시간이 실제와 다르게 기록돼요.**
- 최신 버전에서 정확히 분 단위로 기록되도록 고쳤습니다. 앱을 껐다 켜 최신화하세요.

**Q. 화면이 예전 그대로예요 (바뀐 게 안 보여요).**
- 설치한 앱을 완전히 종료했다가 다시 열면 최신 버전으로 갱신됩니다.

**Q. 주보가 안 보여요.**
- 관리자가 아직 이번 주 주보를 올리지 않았거나, 원본 이미지가 교회 홈페이지에서
  삭제된 경우일 수 있습니다. 관리자에게 문의해 주세요.
